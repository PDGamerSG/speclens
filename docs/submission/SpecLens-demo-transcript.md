## 00:00:00 — A correction the next inspection can recall

A visual inspector can read a specification and still need a quality engineer’s judgment. SpecLens turns that review into a standard the next inspection can recall. This is the live application, using real Meta vision and Hindsight memory. The sample photos are generated, with controlled ink overlays.

## 00:00:18 — Establish the model’s own decision

First, I choose the white marking sample and turn quality memory off. The vision model sees the photo and the base specification, without a learned correction. We keep its actual verdict and explanation rather than forcing a particular answer.

## 00:00:34 — Read the observed result

The live model rejected the part. It already identified a defect, so this is not a manufactured failure. Its original explanation remains on this ticket and in the audit record.

## 00:00:46 — Teach a precise visual standard

The quality engineer records the human standard: sharp white printed characters are ink, while broad natural highlights alone remain acceptable. I explicitly choose reject and the print class, then save the correction. SpecLens keeps the original model reasoning beside this human decision and sends the correction to Hindsight.

## 00:01:11 — Inspect a different source photo

Now I select another marking, from a different source photo, and enable quality memory. The base specification stays the same. Hindsight retrieves relevant standards before the model inspects this new part.

## 00:01:27 — Follow the recalled correction

On the second photo, the live model rejected the part. This inspection cites the exact human correction saved a moment ago. Hindsight supplied the standard, and the base specification stayed fixed. A cited memory is an observed retrieval step even when the model reaches the same verdict.

## 00:01:46 — One part, two real inspections

The comparison runs this second part twice, once without memory and once with it. Both arms use the same image, model, and base specification. I leave the expected decision unlabeled so the screen does not imply a measured score.

## 00:02:02 — Report both outcomes honestly

Without memory, the model rejected the part. With memory, it rejected the part. Both arms reached the same verdict in this run. This is one paired observation, not a general accuracy claim. The memory-enabled arm records the correction it used.

## 00:02:18 — Review what the team has taught

Quality memory shows the saved rule, reviewer, original inspection reasoning, and confirmed sync state. Summarize standards asks Hindsight to reflect over this workspace’s corrections. The summary supports review; the source correction remains the traceable record.

## 00:02:36 — Keep an audit trail across reloads

History keeps all four inspection records, including the two comparison arms. I can search by reviewer and export the complete workspace as JSON. After a reload, the original decision, human correction, and saved comparison are still here.

## 00:02:55 — Keep each standard in its context

Workspace settings make the context explicit. The factory, part family, and exact specification revision define a separate memory bank. Changing the specification starts a new scope. Credentials stay on the server; people remain responsible for disposition.
